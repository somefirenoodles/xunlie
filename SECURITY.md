# Política de seguridad

## Versiones soportadas

Se definirá antes de la primera beta. Hasta entonces no existe una release soportada.

## Reportar

Usa [GitHub Private Vulnerability Reporting](https://github.com/somefirenoodles/xunlie/security/advisories/new). No incluyas secretos, datos personales ni exploit funcional innecesario.

El equipo acusará recibo, hará triage, coordinará corrección/divulgación y acreditará al reportante cuando sea seguro. Los SLO de respuesta se fijarán con la capacidad operativa antes de beta.

## Alcance prioritario

Escape de sandbox, path traversal, exfiltración, confusión de autoridad, manipulación de evidencia, veredicto falso, ejecución desde input no confiable y compromiso de supply chain son críticos para el threat model.
