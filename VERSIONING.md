# Versionado y compatibilidad

- Producto y crates: SemVer.
- Tags: `vMAJOR.MINOR.PATCH`.
- Esquemas y protocolo: identificador propio `xunlie.<name>/vN`.
- GateRecord conserva versión exacta del SQ Plan y reglas.

Antes de `1.0.0` se permiten cambios rápidos, pero toda ruptura exige versión de esquema/protocolo, migración y release notes. Después de 1.0, cambios aditivos compatibles pertenecen a minor; correcciones compatibles a patch; rupturas a major.
